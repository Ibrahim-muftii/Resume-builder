# Resume Builder

Resume Builder is a production-ready web application for creating polished resumes with a guided editor, reusable templates, and export-ready output. It is designed for job seekers, students, career changers, and professionals who want a fast way to build and maintain multiple resume versions.

## Features

- Drag and drop section ordering and item reordering.
- Five resume templates: Modern, Classic, Minimal, Creative, and Executive.
- PDF export for sharing and printing.
- Autosave with save state feedback.
- Authentication with sign up, login, and password recovery flows.
- Dark mode support.
- Resume dashboard for creating, duplicating, deleting, and opening resumes.
- Section-based editing for personal info, experience, education, skills, projects, certifications, languages, and custom content.
- Live preview and template switching.
- Supabase-backed persistence with row-level security.
- Responsive layouts for desktop and mobile.

## Tech Stack

| Layer | Tools |
| --- | --- |
| Framework | Next.js, React, TypeScript |
| Styling | Tailwind CSS, CSS variables |
| UI primitives | Radix UI, local shadcn-style components |
| State | Zustand |
| Forms and validation | React Hook Form, Zod |
| Drag and drop | dnd-kit |
| Animations | Framer Motion |
| Backend and auth | Supabase |
| PDF export | @react-pdf/renderer |
| Notifications | Sonner |
